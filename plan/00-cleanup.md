# Cleanup

**Status**: Completed

Remove dead code, deprecated features, and legacy APIs before building new systems.

---

## Goal

Start from a clean slate. Delete everything that's been replaced by the RSC architecture. No backwards compatibility concerns.

---

## Dependencies

None. This is the first phase.

---

## Delete dead code in compiler.ml

Remove lines 1-135 (the commented-out Eio/Dynlink-based SSG implementation). This code is preserved in git history.

---

## Delete Page.ml

Remove `bin/Page.ml` entirely. The `Loader_page` module type, `register`, `page`, and `get_pages` functions are remnants of the Dynlink-based SSG approach. The new page contract is filesystem-inferred.

---

## Delete Html.re

Remove `bin/Html.re`. The default layout HTML shell will be generated by the compiler as part of the RSC client entry, not hardcoded.

---

## Delete Ppx_deriving_router_runtime.ml

Remove `bin/Ppx_deriving_router_runtime.ml`. Entirely commented out. The `ppx_deriving_router` experiment is abandoned per spec.

---

## Remove @utopia.script from compiler

Strip all `@utopia.script` parsing and handling from `compiler.ml`:

- `page_script` type
- `scripts` field from `route_entry`
- `parse_script_directive`
- `trim_trailing_delimiters`
- `resolve_script_source`
- `script_of_declared_path`
- `scripts_for_page_source`
- `declared_script_sources`
- `script_module_name_from_source`
- `find_script_module_collisions`
- `unique_scripts_of_entries`
- All script-related code in `generate_dune_rules` (script copy rules, script modules in melange.emit)
- `generate_scripts_manifest`
- Writing of `_utopia/scripts.manifest` in the `main` function

---

## Remove scripts manifest from server

Strip all `scripts.manifest` handling from `server.ml`:

- `scripts_manifest_file` constant
- `split_script_fields`
- `parse_assets`
- `load_scripts_manifest`
- `scripts_for_route`
- `render_script_tags`
- All `script_assets` parameters throughout rendering functions
- Remove scripts manifest loading from `main`

---

## Remove scripts manifest from CLI

In `cli.ml`, remove the scripts manifest reference from `print_build_report`.

---

## Clean up Makefile

Remove the `ppx_deriving_router` pin target from the `Makefile`. Keep `server-reason-react` pin.

---

## Update dune stanza in bin/

After removing `Page.ml`, `Html.re`, and `Ppx_deriving_router_runtime.ml`, update `bin/dune`:

- Remove `Page` and `Html` from the Server executable's modules list
- Remove `Ppx_deriving_router_runtime` (it may not be listed since it's commented out, but verify)
- Verify all three executables still compile

---

## Update demo

Update `demo/basic/` to remove any references to the old page contract. The demo pages (`home.re`, `about.re`) use the legacy `Loader_page` style with `path`, `loader`, and typed `data`. Rewrite them to use the new minimal contract:

```reason
[@react.component]
let make = () => {
  <div> {React.string("Home")} </div>
}
```

Regenerate `demo/basic/_utopia/` artifacts (dune, routes.manifest). Remove `scripts.manifest`.

---

## Fix the public_name bug

In `generate_dune_rules`, the library stanza hardcodes `(public_name utopia)` which causes conflicts. Change it to only emit `(name pages)` with no `public_name`. This is a spec requirement.
